# Swift

Original skills in this folder:

- [swift-clean-architecture](swift-clean-architecture): views, view models, use cases, repositories, data sources, entities, DTOs.

For everything else, the best skills already exist, so use them instead of re-writing them here. The AvdLee, twostraws, bocato and efremidze repos list an MIT license. Check the license of the others yourself, and read any skill before installing it.

## Install the AvdLee skills
```bash
npx skills@latest add https://github.com/avdlee/swift-concurrency-agent-skill --skill swift-concurrency
```
Each repo's README has the exact command, and most support Claude Code via `/plugin marketplace add`.
